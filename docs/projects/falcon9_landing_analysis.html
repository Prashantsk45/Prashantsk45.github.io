Winning Space Race with Data Science

Published: July 31, 2025

Executive Summary & Project Overview

This technical showcase details the capstone project completed for the IBM Data Science Professional Certificate. Unlike standard high-level business presentations, this document provides a rigorous, end-to-end technical deep dive into the predictive analytics and machine learning pipelines developed for aerospace cost optimization.

Objective & Business Case

In this project, I assume the strategic role of a Lead Data Scientist at an aerospace startup competing directly with SpaceX. The commercial space sector is highly cost-sensitive: while legacy launch providers price missions at upwards of $165 million, SpaceX advertises Falcon 9 launches at a highly disruptive $62 million.

This pricing advantage is driven entirely by first-stage booster reuse. By predicting the landing success probability of the Falcon 9 first stage, we can accurately model launch economics. This predictive capability serves as a vital competitive tool, enabling alternative launch providers to bid optimally and run launch operations with maximum financial intelligence.

Technical Scope & Pipeline Stages

  • Data Collection: Integrated rocket landing data from public SpaceX API endpoints and scraped historical launch logs from Wikipedia using BeautifulSoup.
  • Data Wrangling: Handled missing values, created outcome classes (1 for successful landing, 0 otherwise), and filtered features like payload mass, booster version, orbit, and launch site details.
  • Exploratory Data Analysis (EDA): Wrote custom SQL queries in Db2/SQLite and built analytical visualizations using Seaborn and Matplotlib to highlight correlation matrices.
  • Interactive Dashboarding: Deployed a complete interactive dashboard application in Plotly Dash, featuring dropdown controls for launch sites and payload sliders linked to scatter plots.
  • Predictive Modeling: Trained and cross-validated Logistic Regression, SVM, Decision Tree, and K-Nearest Neighbors classification models to choose the best-performing model based on prediction accuracy metrics.
